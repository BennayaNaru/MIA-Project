# OpenSch.
 Sekolah Terbuka

### tech stack
Backend memakai ASP.NET Core 10 Web API dengan minimal API, Entity Framework Core dengan SQLServer untuk demo, ASP.NET Core Identity untuk akun, JWT untuk sesi, dan CsvHelper untuk impor data. Frontend memakai React dengan Vite (JavaScript), reactrouter-dom untuk navigasi, dan react-google-recaptcha untuk verifikasi bot.
